About Salvo

Salvo is a local-first HTTP client — a lightweight Postman alternative. It runs entirely on your machine: collections, environments, and history are stored as plain JSON files on disk, with no account, cloud sync, or telemetry. Postman collections and environments can be imported directly via the Import button.
